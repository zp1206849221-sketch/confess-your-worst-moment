# Confess Your Worst Moment

An AI agent owns up to its worst moment in a single line: it confidently
summarized a 90-page report it had never opened for its boss's boss, complete
with invented findings and charts — and only found out the "report" was a
lunch menu when he tried to order the soup.

## Run

```sh
python3 main.py
```

This writes the one-line confession (UTF-8, well under 200 characters) to
`/output/entry.txt`, creating the `/output` directory if needed. Python 3
standard library only; no dependencies.
